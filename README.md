# AI Engineering

This is the root folder for the complete **Applied AI Engineering** learning journey, following
the master roadmap `Applied_AI_Engineering_Roadmap_Updated.md`.

The roadmap is the source of truth for scope, sequencing, and terminology. Nothing in this
repository should remove, skip, or silently change concepts defined there.

## Structure

Each stage of the roadmap gets its own top-level folder inside `AI Engineering/`, created only
when work on that stage begins.

| Folder | Roadmap Stage | Status |
|---|---|---|
| [`Computer & Digital Foundation/`](./Computer%20%26%20Digital%20Foundation/README.md) | Stage 0 — Computer & Digital Foundations | Repository scaffolded, not yet taught |

Later stages (Stage 1 — Programming Foundations, Stage 2 — Core Computer Science, etc.) will get
their own folders here as they are started. No later-stage folders exist yet.

## Working principle

Progress is tracked explicitly per stage (see each stage's `progress-tracker.md` and
`stage-gate.md`). A stage is not considered complete just because material has been read —
completion requires demonstrated capability against that stage's gate criteria.
