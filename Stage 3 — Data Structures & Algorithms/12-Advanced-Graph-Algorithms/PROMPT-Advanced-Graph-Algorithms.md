## Unit 3 — Floyd-Warshall all-pairs shortest paths

## Unit 9 — Network flow and max-flow min-cut introduction
- **L1:** a **flow network**: a directed graph with **non-negative integer capacities**, a **source `s`** and a **sink `t`**; a **flow** assigns each edge a value `0 ≤ f(e) ≤ c(e)` with **conservation** (flow in = flow out at every vertex other than `s` and `t`); the **value** of the flow is the net flow out of `s`; the **maximum flow** problem; examples (pipes, network bandwidth, task throughput); the **residual graph** (for each edge `(u, v)` with flow `f` and capacity `c`: a forward residual edge with capacity `c − f` and a **backward** residual edge with capacity `f` — the ability to **undo** flow); **augmenting path**: a path from `s` to `t` in the residual graph; **Ford–Fulkerson**: repeat — find an augmenting path, push the **bottleneck** along it — until none exists; a hand-run on a 6-vertex network showing residual graphs; **cuts** (`s`–`t` cut: partition `S ∋ s`, `T ∋ t`; capacity = sum of capacities of edges from `S` to `T`) and the **statement** (proved in L3): **max flow = min cut**.

## Unit 14 — Bidirectional search and 0-1 BFS
- **L1:** **bidirectional search**: run one search **forward from the source** and one **backward from the target** until they **meet**; why it can be dramatically cheaper (`2·b^(d/2)` vs `b^d` for branching factor `b` and depth `d` — S3-08 Unit 2 recap with the derivation); **bidirectional BFS** hand-run on a 10-vertex graph showing both frontiers; **0-1 BFS**: when edge weights are only **0 or 1**, Dijkstra's heap is unnecessary — use a **deque**: push `0`-weight neighbors to the **front** and `1`-weight neighbors to the **back**; hand-run on a small grid where some moves are free and others cost 1; the **two ideas in one unit**: both are **specializations that exploit structure to beat the general algorithm**.
- **L2:** **bidirectional BFS** (**alternately expand the smaller frontier; expand a full level at a time; maintain `best = min(dist_f[u] + 1 + dist_b[v])` over edges connecting the two searched regions; stop when `depth_f + depth_b ≥ best`** — **the stopping rule matters: stopping at the first meeting vertex can return a path one longer than optimal in some graphs — a counterexample is demonstrated for the naive rule**; implemented and tested against one-directional BFS; **directed graphs need the reverse adjacency for the backward search**), **bidirectional Dijkstra** (two heaps; `μ = best s–t path length found so far`, updated whenever an edge relaxes a vertex settled/reached in the opposite direction; **stop when `top_f + top_b ≥ μ`** — **stopping when the two searches first settle a common vertex is wrong — counterexample**; implemented with lazy deletion; **reverse graph** construction; counted expansions vs unidirectional Dijkstra on grids and random graphs), **meet-in-the-middle on state spaces** (S3-05/S3-09 link: word ladder, puzzle states; **requires reversible moves**; implemented for word ladder with a wildcard index), **0-1 BFS** (**deque-based; `dist` relaxations with `appendleft`/`append`; stale entries handled by distance checks**; implemented; applications: **minimum obstacles to remove in a grid** (cost 1 to enter a wall cell), **minimum flips to make a path valid (arrow-grid problem)**, **shortest path in a graph with 0/1 edges**, **minimum number of direction changes**), **Dial's algorithm** (**bucket queue for small integer weights up to `C`: array of `C + 1` circular buckets; `O(E + V·C)`** — S3-07 Unit 8 link; implemented and compared with heap Dijkstra by counted operations for `C ∈ {1, 2, 5, 20}`), **graph subdivision as a naive alternative** (replace a weight-`w` edge by `w` unit edges and run BFS — **size blow-up `Σ w`**; - **L3:** **proofs written in full**: (a) **bidirectional BFS stopping-rule correctness**: let `D` = true distance; maintain `best` = shortest path found through edges between the two reached sets; **invariant: after the forward search has completed `a` levels and the backward `b` levels, every path of length `≤ a + b` has been discovered; (b) **bidirectional Dijkstra's stopping rule**: **if `top_f + top_b ≥ μ` then no path shorter than `μ` exists** — proof by contradiction (suppose an `s–t` path `P` of length `< μ` exists; every vertex whose forward distance is `≤ top_f` is already settled by the forward search, and every vertex whose backward distance is `≤ top_b` is settled by the backward search;
