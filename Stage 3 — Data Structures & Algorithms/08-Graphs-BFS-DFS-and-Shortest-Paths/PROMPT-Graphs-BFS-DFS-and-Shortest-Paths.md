- **L3:** **proofs**: (a) **a graph is bipartite ⇔ it contains no odd cycle** (⇒: along a cycle colors alternate, so the length is even; ⇐: color each component by parity of BFS distance from a root and show that a same-color edge creates an odd cycle through the BFS tree — full proof); (b) **BFS two-coloring correctness** (the algorithm succeeds iff the graph is bipartite; the reported conflict edge together with tree paths gives an **odd cycle** — constructive proof used by the witness extractor); (c) **DFS version equivalence**; (d) **union-find-with-parity correctness** (invariant: `parity[x]` = parity of the path from x to its root; merging two sets with a required relation fixes the root-to-root parity; a conflict arises iff an edge connects two vertices already in one set with equal parity); (e) **complexity**: O(V + E) for BFS/DFS coloring, O(E·α(V)) for the DSU version; (f) **trees and grids are bipartite** (proof: no cycles / coordinate-sum parity); (g) **the greedy-coloring `Δ + 1` bound** and the **non-optimality** counterexample (a crown graph ordering); (h) **why bipartiteness matters algorithmically** (matching and flow are easier — named; independent sets — named).
