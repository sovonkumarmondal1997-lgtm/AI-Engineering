## Unit 1 — Confusion-matrix-driven error analysis

- **L1:** **the confusion matrix (recall 5A-06 Units 1–2; this unit uses it as an analysis instrument): rows are true classes, columns are predictions (the convention is stated and tested against `sklearn.metrics.confusion_matrix`); the diagonal is correct, every off-diagonal cell is a specific kind of mistake; total errors `= n − trace(C)`; accuracy `= trace(C)/n`**; **three normalisations, each by hand: raw counts, row-normalised (recall per true class: "of the true `i`, how many were predicted `j`"), and column-normalised (precision per predicted class: "of the predicted `j`, how many truly were `i`")**; **reading a matrix in order: (1) support (row sums) and prediction counts (column sums), (2) the diagonal rates, (3) the largest off-diagonal cells in counts and in rates, (4) asymmetry (`C_{ij}` vs `C_{ji}`), (5) the cost of each cell**; **binary special case: TP/FP/FN/TN and the cells' names**; **a first worked example by hand: the 12-row 3-class table: the matrix, three normalisations, per-class precision/recall/F1, macro and micro averages, the most confused pair, and the same in scikit-learn**; **the error budget: a pie of the errors by cell (what share of all mistakes each off-diagonal cell is)**; ≥ 3 worked examples.
- **L2:** **confusion-matrix analysis in depth (derived/measured)**: **(1) counts vs rates (a cell with few rows has an unstable rate: show every rate with its support and a Wilson interval; a table of "largest confusions" ranked by *count* and by *rate* and why they differ); (2) **the cost matrix** `L_{ij}` and **expected cost** `Σ_{ij}L_{ij}C_{ij}/n` (recall 5A-06 Unit 4; the same model can look better or worse under different cost matrices; a cost-weighted error budget by cell; sensitivity of the ranking of cells to the cost matrix: a table over a grid of cost ratios); (3) **per-class metrics as functions of the matrix** (precision, recall, F1, specificity, balanced accuracy; macro/micro/weighted averages; `zero_division` conventions; classes never predicted; classes with zero support: stated rules and tests); (4) **top-`k` and hierarchical confusions** (when classes have a hierarchy (e.g., billing vs billing-refund), merge-and-recompute to see whether errors are within-group or across-group; the "grouped confusion matrix" and a merge-matrix identity); (5) **the confusion graph** (nodes are classes, edges weighted by off-diagonal counts; strongly connected pairs suggest class definitions that overlap or a missing feature; a worked example with a planted class-overlap); (6) **uncertainty in the matrix** (each row is multinomial given the support; simultaneous intervals for many cells; bootstrap of the matrix at the unit of independence; stability of the "top confusion" ranking across bootstrap resamples: the probability that the top-ranked cell remains top, with an interval); (7) **out-of-fold analysis** (where the matrix comes from: `cross_val_predict` on training data with grouped/time-aware folds, or a validation set; the sealed test set is not used for debugging; fold-ordering semantics of `cross_val_predict` and its `method` argument `[VERSION-SENSITIVE]`; the leakage trap of tuning *and* analysing on the same predictions: logged looks); (8) **from matrix to hypotheses** (each large cell yields candidate explanations: class overlap, missing features, label ambiguity, data quality, threshold effect, a sub-population: a hypothesis table with the *next* diagnostic for each; the matrix identifies *where*, never *why*); (9) **multi-label and regression notes** (named: per-label matrices; for regression, error-by-bin tables and residual analysis recalled from 5A-04 Unit 6, with the same "where before why" discipline); (10) **thresholds and the matrix** (moving a decision threshold moves mass between the FP and FN cells: a worked sweep; the matrix is a function of the threshold; ROC/PR remain 5A-06; threshold optimisation methods are 5B `03`); (11) **reporting** (a matrix with row-normalised percentages, counts, supports, and intervals; a text alternative; colour is never the only encoding)**.
- **L3:** **proofs, written in full:** (a) **accuracy `= trace(C)/n`; the error count `= Σ_{i≠j}C_{ij}`; micro-averaged precision, recall, and F1 equal accuracy in single-label multi-class classification (recalled from 5A-10 Unit 7 and proved here from the matrix: `ΣTP = trace`, `ΣFP = ΣFN = Σ_{i≠j}C_{ij}`)** — complete; (b) **macro-recall equals balanced accuracy `= (1/K)Σ_iC_{ii}/n_{i·}`; it equals accuracy iff the class-weighted recall equals the unweighted mean (e.g., equal supports or equal recalls): a counterexample with a 95/5 split** — complete; (c) **expected cost decomposition: `E[L] = Σ_{i}π_i Σ_j L_{ij}·P(ŷ = j | y = i)` where `π_i = n_{i·}/n`; the cost of a cell is `π_i L_{ij}r_{ij}` with `r_{ij}` the row rate; reordering cells by count vs by cost can differ: a computed example with unequal `L`** — complete; (d) **grouped confusion matrices: merging classes `A ∪ B` into one group by summing the corresponding rows and columns yields the confusion matrix of the grouped problem; the grouped accuracy is `≥` the original accuracy (within-group confusions become correct); the gain equals the within-group off-diagonal mass over `n`** — complete (counting); (e) **multinomial rows: given row support `n_{i·}`, the row `(C_{i1},…,C_{iK})` is multinomial with probabilities `r_{ij}`; the cell marginal is binomial; the Wilson interval for a cell has approximately `1 − α` coverage for a single cell; for `m` cells simultaneously the Bonferroni-adjusted level `α/m` gives family-wise coverage `≥ 1 − α` by the union bound** — complete (union bound; the multinomial-to-binomial marginal); coverage studies by simulation: `EVIDENCE ONLY`; (f) **top-confusion stability: if the two largest off-diagonal *counts* are `a > b` with independent binomial noise, the probability that the observed order flips is approximately `Φ(−(a − b)/√(a + b))` (normal approximation to the difference of Poisson counts; **a "top confusion" that flips in 30% of bootstrap resamples (seeded)**; **numerical analysis**: **spec-literal confusion, normalisations, per-class metrics, cost decomposition, grouped matrices, and cell intervals vs scikit-learn/SciPy on tiny and random inputs (including empty classes, never-predicted classes, label permutations, and `labels=` ordering)**; **tool card** for `errlab.confusion` (confusion matrix with explicit orientation and label order; three normalisations with `zero_division` rules; per-class and averaged metrics; cost matrices, cost-weighted budgets, and sensitivity grids; ## Unit 2 — False-positive and false-negative inspection

- **L1:** **numbers say where; looking at actual examples says what; inspection is reading a *sample* of the model's mistakes in a structured way**; **why sampling: you cannot read thousands of errors; how you sample decides what you will believe: reading only the most confident errors, or only the ones you happen to remember, produces a story, not a measurement**; **the vocabulary: false positive (predicted positive, truly negative), false negative (the reverse); for multi-class, "false positive for class `j`" is column `j` off-diagonal and "false negative for class `i`" is row `i` off-diagonal**; **a simple inspection protocol by hand: (1) choose the cell(s) to inspect from the matrix (Unit 1); (2) draw a seeded random sample of fixed size from the cell; (3) record each example's ID, the model's score, and a free-text note on why it was wrong; (4) group the notes into candidate causes; (5) record the sampling rule and the seed**; **a first worked example by hand: 40 false negatives in a 400-row table; a 10-row seeded sample; the tagging sheet; the estimated share of one cause with an interval**; ≥ 3 worked examples.
- **L2:** **inspection in depth (derived/measured)**: **(1) sampling designs (simple random within a cell; stratified by cell, class, score band, or slice; systematic; "most confident errors" and "near-threshold errors" as *named, labelled* purposive samples that support hypothesis generation only, never share estimates; the fixed, seeded, logged sampling rule; a sampling frame defined before looking); (2) **estimating the share of an error category** (with a simple random sample of `m` errors from `N` and `x` tagged `t`: the estimate `x/m`, the Wilson interval, and the finite-population correction when `m/N` is not small; planning `m` for a target half-width `h`: `m ≥ z²p(1 − p)/h²` with the worst case `p = ½`, and the FPC-adjusted form; stratified estimators `Σ_h W_h p̂_h` with the variance formula; the effect of tagging error on the estimate: a misclassification-corrected estimator via the Rogan–Gladen form of Unit 5); (3) **the tagging sheet** (columns: example ID, stratum, model score/prediction, true label, tags from a *versioned* taxonomy (Unit 4), confidence of the tagger, a free-text note, tagger ID, timestamp as metadata; blind tagging where possible (the tagger does not see the model's prediction when judging the "true" label: a measured effect of anchoring in a seeded simulation); (4) **two taggers and agreement** (Cohen's kappa recalled from 5A-10 Unit 7; percent agreement; the kappa paradox; adjudication rules; the tag-level reliability and what to do when it is low: tighten definitions, not just average); (5) **threshold-aware inspection** (for score-based models, FP and FN trade off along the threshold; inspect errors at the operating threshold *and* sample from score bands to see how the mix changes; recall that threshold choice is 5A-06/5B `03`); (6) **inspecting false positives vs false negatives asymmetrically** (a false negative is often unseen in production (no label arrives): the label-delay and selection-bias caveat; sampling negatives for review to estimate the FN rate: a stratified-audit design with the Horvitz–Thompson-style weights `1/π_i` for unequal inclusion probabilities, derived in L3); (7) **inspection and the test set** (never inspect the sealed test set; inspect out-of-fold or validation errors; if inspection motivates a change, re-measure on fresh rows; inspected rows are *burned* for confirming that fix: a measured optimism when a fix is validated on the inspected rows: seeded demonstration with intervals); (8) **annotation guidelines and ambiguity** (when two careful taggers disagree on whether a prediction was "really wrong", the example is ambiguous: label ambiguity is a finding (Unit 5), recorded as its own tag; guidelines are versioned); (9) **privacy and exemplars** (exemplars in reports are synthetic or redacted; access control; awareness only); (10) **tooling** (a spreadsheet-like tagging sheet as CSV/JSONL with a strict schema; a CLI that draws the sample from the log, writes the sheet, and later ingests it with validation; the sampling rule and seed in the `replab` log); (11) **from inspection to hypotheses** (a table of candidate causes with the *test* that would confirm each, e.g., a slice check (Unit 3), a data check (Unit 5), a controlled change (Units 6–7))**.
- **L3:** **proofs, written in full:** (a) **sample size for a proportion: for a simple random sample with replacement of size `m`, `p̂` has `Var = p(1 − p)/m ≤ 1/(4m)`; the normal-approximation half-width `z√(p(1 − p)/m)` is at most `z/(2√m)`, so `m ≥ (z/2h)²` guarantees half-width `≤ h` for any `p` (`m = 385` for `h = 0.05`, `z = 1.96`: computed); the finite-population version without replacement multiplies the variance by `(N − m)/(N − 1)`** — complete (variance of a hypergeometric proportion); (b) **stratified estimator: with strata weights `W_h = N_h/N` and within-stratum samples of size `m_h`, `p̂_st = Σ_hW_hp̂_h` is unbiased for the population proportion and `Var(p̂_st) = Σ_hW_h²p_h(1 − p_h)/m_h` (with replacement); for proportional allocation `m_h ∝ N_h` this is no larger than the simple-random-sample variance: prove `Var_prop ≤ Var_srs` via the between-strata variance term** — complete; (c) **Horvitz–Thompson estimator: if example `i` is included with known probability `π_i > 0`, `Σ_{i∈S}z_i/π_i` is an unbiased estimator of `Σ_iz_i` (the indicator expectation argument); for a stratified audit with inclusion probabilities `m_h/N_h` it reduces to `Σ_hN_h p̂_h`** — complete; (d) **Cohen's kappa: `κ = (p_o − p_e)/(1 − p_e)` with `p_e = Σ_kp_{k·}p_{·k}`; range `[−1, 1]`; `κ = 1` iff perfect agreement; the kappa paradox: with skewed marginals, `κ` can be low despite high `p_o` (a computed 2×2); a worked interval for `κ` by bootstrap** — complete (recalled; extended with the paradox example); (e) **the FN rate from an audit of predicted negatives: if a random fraction `f` of predicted negatives is labelled, the observed FN count `x` among `m = f·N₋` labelled gives `N̂_FN = x/f` and `FN-rate = N̂_FN/(N̂_FN + TP)` with a delta-method or bootstrap interval; the estimator is unbiased for the FN count under simple random sampling (HT with `π = f`)** — complete; (f) **optimism of fix-on-inspected-rows: if a rule is chosen to fix the `m` inspected errors (it corrects all of them by construction), the measured recovery on those rows is 100% while the expected recovery on fresh errors from the same cell is the rule's true coverage `ρ`; with `m` errors sampled and a rule family of size `R` chosen to maximise coverage, the expected measured coverage exceeds the true by a selection term bounded by `√(ln R/(2m))` (Hoeffding + union bound)** — complete for the bound; the demonstration by simulation: `EVIDENCE ONLY`; **counterexamples**: **"most confident errors" reading as a cause that explains 5% of errors (computed vs stratified estimate)**; **an anchored tagger "confirming" the model's label (seeded)**; **a kappa of 0.28 with 90% raw agreement (computed)**; **a fix validated on its own inspected rows (seeded; intervals)**; **a convenience sample over-representing short examples (computed bias)**; **numerical analysis**: **spec-literal samplers, Wilson/FPC intervals, stratified and HT estimators, kappa, and sample-size calculators vs `scipy.stats` and exact enumeration on tiny populations**; **tool card** for `errlab.inspect` (seeded, logged samplers: simple, stratified, systematic, purposive (labelled); sample-size and FPC calculators; stratified and Horvitz–Thompson estimators with intervals; FN-rate audit designer; tagging-sheet writer/reader with strict schema and blind mode; agreement statistics (percent, kappa with bootstrap interval); burned-row registry and a fresh-row re-measurement helper; spec-literal references; stable errors; no input mutation).
- **L4:** **inspection as a process (an MLOps lens)**: **an inspection protocol checked into the repository (sampling rule, sizes, taxonomy version, tagger instructions, agreement threshold for proceeding: `HEURISTIC`); inspection budgets in hours and rows, counted; rotating reviewers to avoid single-person blind spots; review queues that mix model-flagged and randomly sampled items so that the audit sample is unbiased; ownership of the taxonomy and sheets; retention and privacy of reviewed examples; feeding confirmed errors into a golden regression set (Unit 4) and confirmed label errors into a relabelling queue (Unit 5)**; hostile inputs (an empty cell; a cell smaller than the requested sample; duplicate IDs in the sheet; tags outside the taxonomy; a tagger who skips rows; mixed taxonomy versions; examples missing from the log; a sampling frame that changed after the draw); **exhaustive verification** of the sample-size and FPC formulas **over all small populations by exact hypergeometric enumeration**, of unbiasedness of the stratified and HT estimators **by enumeration of all samples for `N ≤ 8`**, of kappa's range and special cases **over all 2×2 and 3×3 tables with `n ≤ 8`**, and of the monotonicity of the threshold-sweep error mix **over all small score tables** (domains named and sized; `EVIDENCE ONLY`); mutation lab (sample drawn from the test set; unseeded draw; sampling frame defined after looking; FPC omitted; strata weights wrong; HT weights inverted; anchored tagging; taxonomy not versioned; the fix re-measured on inspected rows; kappa computed with the wrong `p_e`) with no surviving mutants; case study: a "root cause" claimed from the ten most vivid errors and a fix validated on the rows that motivated it (original synthetic reproductions with a stratified, logged sample and fresh-row re-measurement as fixes).

## Unit 3 — Performance slices and subgroups

- **L1:** **a slice is a subset of rows defined by a rule (a feature range, a category, a metadata field, a time window); a slice metric is the usual metric computed on only that subset; an overall metric can hide a bad slice because it is a *weighted average* of slice metrics**; **where slices come from: business-defined (region, device, language, customer type), data-defined (feature bins, missingness patterns, length buckets), model-defined (confidence bands, predicted class), and time-defined**; **the slice table: slice name, size `n_S`, share of data, the metric with an interval, and the gap to the overall metric**; **small slices are noisy: a 4-out-of-5 slice and a 800-out-of-1000 slice have the same rate and very different certainty**; **Simpson's paradox in words: a model can be better in *every* slice and worse overall (or the reverse) because slice sizes differ between two groups: a first worked example with exact counts**; ≥ 3 worked examples.
- **L2:** **slices in depth (derived/measured)**: **(1) slice definition discipline (pre-registered slices from a written list *before* looking at errors; exploratory slices labelled exploratory; every slice examined is counted; (5) **intersectional slices and the combinatorial explosion** (`d` binary attributes give `3^d − 1` conjunctive slices (each attribute fixed to 0, 1, or free); search budgets; hierarchical testing (test coarse slices first, refine only where the parent is significant); ## Unit 7 — Ablation studies and impact prioritisation

- **L1:** **an ablation study asks "what happens to the result if I remove or change *one* component?": drop a feature group, remove a preprocessing step, replace a model with a simpler one, remove a data source; the difference in the metric estimates that component's contribution *in this system*, not its importance in general**; **the minimal honest ablation: a fixed baseline (the full system), a fixed evaluation protocol, the same seeds and splits (paired, 5A-11), one change at a time, the metric difference with an interval, and every ablation reported**; **impact prioritisation in plain words: a list of possible fixes is ranked by (how much error it could remove) × (how likely the fix works) ÷ (how much it costs), with uncertainty, so the team works on the best bets first**; **a first worked example by hand: a three-component system, three ablations, their paired differences with intervals, and the resulting ranking of components; then a five-item fix list scored by a simple expected-gain-per-cost rule**; **a ceiling analysis in one line: pretend a category of errors is fixed perfectly and recompute the metric: that is the *most* you could gain from it**; ≥ 3 worked examples.
- **L2:** **in depth (derived/measured)**: **(1) ablation design (removal vs replacement (ablate a feature by dropping the column and *retraining* vs by permuting/masking at inference without retraining: these answer different questions: "what is this feature's marginal contribution to a *retrained* model" vs "how much does *this trained model* rely on it"; a seeded demonstration where they disagree because of correlated features); component granularity (feature groups, not single columns, when features are correlated); the baseline definition and the ablation grid written in the pre-registered plan (5A-11 Unit 4); paired seeds/splits; intervals; the number of ablations counted for multiplicity); (2) **one-at-a-time vs factorial designs** (one-factor-at-a-time misses interactions; the `2^k` full factorial estimates all main effects and interactions; fractional factorials named `CITED [VERIFY]`; the main-effect and interaction estimators derived in L3; a seeded study where an interaction makes one-at-a-time ablations mislead (two components that each add nothing alone but help together, and the reverse)); (3) **attribution of the total gain** (when a baseline-to-full improvement has several components, no unique split exists if there are interactions; the **Shapley value** of a component (the average marginal contribution over all orderings) is a well-defined fair split with the efficiency property: the shares sum to the total gain; computed exactly for `k ≤ 5` components by enumerating subsets (`2^k` retrains: budgeted); `CITED [VERIFY]` origin; the caveat that Shapley attributions answer a *bookkeeping* question and not a causal one); (4) **ceiling (oracle) analysis** (fix a taxonomy category or slice perfectly in the evaluation data (replace the model's predictions there with the truth) and recompute the metric: the upper bound of the gain from that category; (5) **impact estimation** (`expected gain = (share of errors in category) × (fraction fixable by the intervention) × (total error)` with uncertainty from the stratified share interval and a pilot-based interval for the fixable fraction; the probability that the top-ranked item is truly best (via Monte-Carlo over the input uncertainties) is reported); (7) **portfolio view** (several cheap fixes vs one big fix; diminishing returns and overlapping error sets (fixes that address the *same* errors do not add: the union bound and inclusion–exclusion on error sets; a worked example); dependencies between fixes (a data fix enabling a model fix)); (8) **ablation pitfalls** (confounding with retuning (an ablated model may need different hyperparameters: tune each arm under the same budget); leakage between arms; shared seeds; a baseline that is itself weak (everything helps); ablating after the fact on the test set; reporting only ablations that "worked"; ablations on one dataset generalising to another); (9) **reporting** (an ablation table: component, change, `k` seeds, mean difference with interval, adjusted p-value, effect size, slice effects; a prioritisation table with expected gain, cost, interval, and rank-stability; the ledger and report come from `replab`)**.
- **L3:** **proofs, written in full:** (a) **factorial effects: for a `2^k` design with factors coded `±1` and a response `Y`, the main effect of factor `i` is `E_i = (Ȳ_{i=+1} − Ȳ_{i=−1})`, the two-factor interaction `E_{ij} = ½[(Ȳ_{i=+1,j=+1} − Ȳ_{i=−1,j=+1}) − (Ȳ_{i=+1,j=−1} − Ȳ_{i=−1,j=−1})]` (state the convention), and with `Y = β₀ + Σβ_ix_i + Σβ_{ij}x_ix_j + ε`, `E_i = 2β_i` and `E_{ij} = 2β_{ij}` (derive from orthogonality of the `±1` contrasts: `Σx_ix_j = 0` over the full design); the estimators are unbiased and, for `r` replicate seeds per cell, `Var(E_i) = 4σ²/(N)` with `N = r·2^k` total runs (derive)** — complete; (b) **one-at-a-time bias under interaction: ablating factor `i` from the all-`+` baseline estimates `2β_i + 2Σ_{j≠i}β_{ij} + (higher-order terms)`-type quantities (derive for `k = 2`: the OAT ablation effect from `(+,+)` to `(−,+)` equals `β_i·(−2) + β_{ij}·(−2)x_j`-form: show that it equals `2β_i + 2β_{ij}` in magnitude and differs from the main effect `2β_i` by exactly the interaction when the other factor is at `+`); (e) **overlap of fixes: for fixes `A`, `B` with fixed-error sets `F_A, F_B`, the combined fixed count is `|F_A ∪ F_B| = |F_A| + |F_B| − |F_A ∩ F_B| ≤ |F_A| + |F_B|`; so gains are sub-additive when error sets overlap and equal to the sum iff disjoint;
