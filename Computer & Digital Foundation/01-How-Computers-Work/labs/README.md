# Module 0.1 Labs

**Status:** Not Started

Hands-on, observational labs for Module 0.1. These labs let the learner *see* the hardware and
storage concepts from the numbered concept files on their own real machine, using simple
inspection tools — no programming knowledge is required for this module's labs (that begins in
Module 0.2's process lab and Stage 1).

## Labs in this module

| # | Lab | Concepts exercised |
|---|---|---|
| 1 | [`01-system-information-lab.md`](./01-system-information-lab.md) | Motherboard, CPU, cores, RAM, storage, GPU |
| 2 | [`02-memory-and-storage-lab.md`](./02-memory-and-storage-lab.md) | Cache, RAM, storage, HDD vs SSD |
| 3 | [`03-cpu-observation-lab.md`](./03-cpu-observation-lab.md) | CPU, cores, instructions (observed indirectly via load) |
| 4 | [`04-program-execution-observation-lab.md`](./04-program-execution-observation-lab.md) | Processes, what happens when a program starts |

## How to use these labs

- Complete labs **after** reading the concept file(s) they exercise, not before — they are meant
  to confirm and observe what was just read, not to teach it from scratch.
- Each lab is self-contained: objective, prerequisites, tools, procedure outline, what to record,
  expected learning outcome, and troubleshooting.
- These labs are **specifications**, not walkthroughs with pre-filled answers. Actual command
  output, screenshots, and findings are recorded by the learner during the teaching phase.
- Labs assume a Linux, Ubuntu, or WSL2 environment (matching Stage 0's overall prerequisite).
