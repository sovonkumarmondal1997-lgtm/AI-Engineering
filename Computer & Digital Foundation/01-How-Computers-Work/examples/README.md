## How these will be used

- Each example is written to require **no prior technical background** — every one is something
  a complete beginner has plausibly already experienced (opening an app, saving a file, a slow
  laptop, a loading screen).
- Examples are attached to concept files under that file's "7. Real-world example" section once
  lesson content is written — this index exists so that section is never left to be improvised
  during teaching.
- Additional examples may be added here as they come up during teaching; this list is a starting
  plan, not a fixed final list.
