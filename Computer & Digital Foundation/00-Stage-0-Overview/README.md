# 00 — Stage 0 Overview

This folder contains the planning and tracking material for Stage 0, separate from the teaching
content itself (which lives in modules `01-How-Computers-Work/` through `04-Developer-Environment/`).

## Contents

- [`learning-plan.md`](./learning-plan.md) — the recommended path through Stage 0's four modules.
- [`progress-tracker.md`](./progress-tracker.md) — a checklist of every concept, lab, exercise,
  and project in Stage 0, with a status for each.
- [`stage-gate.md`](./stage-gate.md) — the explicit, demonstrable criteria required to consider
  Stage 0 complete.
- [`glossary.md`](./glossary.md) — a running glossary of every term introduced in Stage 0.

## How to use this folder

1. Start with `learning-plan.md` to see the intended sequence.
2. As work happens in each module, update the corresponding rows in `progress-tracker.md`.
3. Add new terms to `glossary.md` as they're encountered.
4. Before considering Stage 0 finished, walk through every item in `stage-gate.md` and confirm it
   can genuinely be demonstrated — not just recognized from reading.

Nothing in this folder is marked complete yet. Status fields are placeholders (`Not Started`)
until real learning happens.
