# Module 0.3 — Command Line

**Status:** Not Started

## What this module covers

Covers the core command-line tools needed for all future work: pwd, ls, cd, cp, mv, rm, mkdir, cat, less, head, tail, grep, find, sort, uniq, cut, xargs, pipes, redirection, environment variables, shell scripts, and permissions. Introduces the shell tools used throughout the roadmap: Bash, Git Bash, WSL2, PowerShell.
