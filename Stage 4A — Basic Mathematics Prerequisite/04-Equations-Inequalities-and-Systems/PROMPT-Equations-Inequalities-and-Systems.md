## Unit 5 — Factoring trinomials and solving quadratics by factoring

## Unit 6 — Completing the square
- **L1:** **the idea** (turn `x² + bx` into a perfect square by adding `(b/2)²`); **the identity** `x² + bx = (x + b/2)² − (b/2)²`; **solving `(x + h)² = k`** (**two solutions `−h ± √k` if `k > 0`; one if `k = 0`; none in the reals if `k < 0`**); **square roots in exact form** (M01 Unit 6 and **forward link to `../05-Exponents-Roots-and-Growth/04-fractional-exponents-roots-and-radicals.md`**; simplifying `√12 = 2√3` by extracting square factors); Python `math.isqrt` for exact perfect-square checks.
- **L2:** **completing the square for monic quadratics, then non-monic (divide by `a` first — a reversible step for `a ≠ 0`)**; **fractional `b/2`** (exact `Fraction`); **vertex form `a(x − h)² + k`** (the algebra only; **graphs forward to `../07-Functions-and-Graphs/08-quadratic-functions-and-parabolas.md`**); **the minimum (or maximum) value of a quadratic by algebra alone**: for `a > 0`, `ax² + bx + c ≥ c − b²/(4a)` with equality at `x = −b/(2a)` (**no calculus**; forward link to `../../Stage 4B — Mathematics for Machine Learning/05-Derivatives-and-Single-Variable-Optimization`); **ML-flavored use**: the one-parameter quadratic loss `a w² + b w + c` has its minimizer at `−b/(2a)` (stated numbers; **Stage 4B/4C name the general theory**).

## Unit 10 — Absolute value equations and inequalities
- **L1:** **`|x|` is the distance from `x` to `0`** (M01 Unit 3 recall); **`|x − a|` is the distance from `x` to `a`**; **`|x − a| = r`** (for `r > 0`: `x = a − r` or `x = a + r`; `r = 0`: `x = a`; `r < 0`: **no solution**); **`|x − a| < r`** (between `a − r` and `a + r`); **`|x − a| > r`** (outside); **checking**; Python `abs`.
- **L2:** **isolating the absolute value first** (`2|x − 1| + 3 = 11`); **the case split** (`A ≥ 0` and `A < 0` give two linear problems; solve each *within its case*); **`|A| = B` requires `B ≥ 0`** (a **built-in extraneous-solution check** — forward to Unit 15); **`|A| = |B|`** (`A = B` or `A = −B`); **inequalities with absolute values** (intersection for `<`, union for `>` — **Unit 9 tools**); **ML-flavored tolerance bands with stated numbers**: `|prediction − target| ≤ ε` as an interval around the target (and the link to `math.isclose` absolute tolerance, M01 Unit 7); **mean absolute error named** (forward; not taught).
- **L3:** **proofs, written in full:** (a) **`|x| = r ⇔ x = ±r` for `r ≥ 0`** (case analysis on the sign of `x`); (b) **`|x| < r ⇔ −r < x < r` and `|x| > r ⇔ x < −r or x > r`** (with the degenerate cases `r ≤ 0` stated: `|x| < r` has no solutions for `r ≤ 0`; `|x| > r` holds for all `x` when `r < 0`); (c) **`|A| = |B| ⇔ A = B or A = −B`** (from `A² = B²` and the zero-product property applied to `(A − B)(A + B) = 0`, and the fact that `|A|² = A²`); (d) **the triangle-inequality link** (M01 Unit 3): `|a − c| ≤ |a − b| + |b − c|` as the reason distances behave; **exhaustive verification**: for all integers `a, r` in a stated range and all relation symbols, the solver's `IntervalSet` vs brute-force membership over a rational grid; `|A| = B` families with the sign condition vs brute force.
- **L4:** **sums of absolute values** (`|x − 1| + |x − 4| = 5`): **split at the breakpoints (where each absolute value's inside is zero), solve a linear equation on each piece, and intersect each piece's solutions with the piece's interval — using the `IntervalSet` type**; **why the case-split method is correct** (a piecewise-linear function; stated and justified by the case analysis, not by graph-reading); **caps on the number of breakpoints**; **an absolute-value tool** `absolve` (Tool card: equations and inequalities with one or several absolute values over linear insides; exact `IntervalSet`; case-by-case derivation; cross-check by brute force and test points); hostile inputs (nested absolute values — **refused or handled by documented recursion with a cap**); **testing**: exhaustive oracles; mutation lab (case boundaries inclusive on both sides; extraneous root accepted; `|A| = B` with `B < 0` solved anyway) with no surviving mutants.

## Unit 13 — Special cases: no solution and infinitely many solutions

## Unit 15 — Checking solutions and extraneous results
