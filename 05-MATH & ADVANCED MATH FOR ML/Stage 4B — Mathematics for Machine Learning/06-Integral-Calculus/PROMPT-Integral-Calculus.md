## Unit 1 — Antiderivatives and the indefinite integral

- **L1:** **an antiderivative of `f` is a function `F` with `F' = f`**; **the family `F + C`** (why the constant: two antiderivatives differ by a constant — **a consequence of the mean value theorem from S4B-05**); the **indefinite integral `∫ f(x) dx = F(x) + C`**; **reversing the derivative table**: `∫ xⁿ dx = xⁿ⁺¹/(n + 1) + C` (`n ≠ −1`), `∫ 1/x dx = ln|x| + C` (**the absolute value, and the domain split `x < 0`, `x > 0`**), `∫ eˣ dx = eˣ + C`, `∫ eᵃˣ dx = eᵃˣ/a + C`, `∫ aˣ dx`, `∫ sin x dx = −cos x + C`, `∫ cos x dx = sin x + C`, `∫ sec² x dx = tan x + C`; **linearity** (`∫ (af + bg) = a∫f + b∫g`); **checking every answer by differentiating it** (the antiderivative-checking rule) with a small exact `Fraction` evaluation and `sympy.diff`; **initial-value problems** (`F' = f`, `F(x₀) = y₀` ⇒ fix `C`); polynomials integrated term by term; ≥ 3 worked examples.
