## Unit 3 — The Poisson distribution

- **L1:** **the Poisson distribution: counts of events in a fixed interval when events occur independently at a constant average rate** (requests per minute, errors per hour — **as a *model*, with the assumptions listed: independence, constant rate, no simultaneous events**); **the pmf `P(X = k) = e^{−λ}λᵏ/k!` for `k = 0, 1, 2, …`** (**the rate `λ` is the mean count per interval — the pinned parameterisation**; `Poisson(λt)` for a window of length `t`); **mean `λ` and variance `λ` (the defining diagnostic: variance = mean)**; **the shape for `λ = ½, 1, 4, 20`** (skewed to bell-like); **hand computations**: `P(X = 0) = e^{−λ}`, `P(X ≥ 1) = 1 − e^{−λ}`, with high-precision `Decimal` values; **the Poisson as the limit of the binomial for many trials with small success probability (`n → ∞`, `p → 0`, `np = λ` fixed) — "the law of rare events"** with a numerical table comparing `Binomial(n, λ/n)` with `Poisson(λ)` for `n = 10, 100, 1000` (high-precision `Decimal`; the maximum pmf difference); **counts in ML systems (original illustrations): errors per batch, requests per window, tokens flagged per document — each paired with the question "are the assumptions plausible?"**; **simulation with `rng.poisson(lam, size)` (`[VERIFY]`) and comparison with the exact pmf in standard-error units**; ≥ 3 worked examples.
