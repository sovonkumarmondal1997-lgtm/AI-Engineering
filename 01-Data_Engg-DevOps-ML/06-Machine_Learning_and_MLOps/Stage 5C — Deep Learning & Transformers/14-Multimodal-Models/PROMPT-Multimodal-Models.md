**Design decisions to state in Unit 0 and Unit 8 (deliberate, `JUDGEMENT`):**

1. **Planted multimodal worlds replace pretrained models.** The project title says "CLIP", and real CLIP-style results require pretrained weights and web-scale pairs, which the zero-budget, offline rule forbids. **The graded project therefore builds and trains a tiny CLIP-style dual encoder on the synthetic scene world and performs zero-shot classification of held-out class compositions with prompt templates.** **An optional path lets a learner who already holds locally licensed weights run the same harness on them; it is reported separately, is never graded, and no number from it appears in the syllabus.** The module teaches the mechanism, the mathematics, the measurement, and the pitfalls; it asserts nothing about any real model.
2. **Ground truth is planted so that "uses the image" is measurable.** Every scene has exact attributes (colour, shape, count, position, relation); every caption and question has an exact oracle answer; **blind baselines (question-only, caption-only, image-only, shuffled-pair) and shortcut baselines (a background that correlates with the label) are mandatory companions of every headline number**; **modality-ablation and counterfactual-image tests (swap one attribute in the image and check that the output changes accordingly) separate "the model uses the image" from "the model uses a prior".**
3. **Interfaces are counted before models are compared.** Every modality has a stated interface: **patches per image `N = (H/P)(W/P)`, frames per second of audio and tokens per second after downsampling, denoising steps and network evaluations per generated sample**; **cost is in tokens, FLOPs (Module 10/12 formulas), and bytes of cache, and methods are compared at equal compute where stated**; **no wall-clock claim beyond the learner's own CPU at the edge, labelled `[ILLUSTRATIVE]`.**
4. **Exact oracles for every transform.** Patchify against a strided convolution; the symmetric contrastive loss against a brute-force double loop; the STFT and mel features against a direct DFT; CTC loss against enumeration of all alignments; word-error rate against a dynamic-programming edit distance; the diffusion forward process against its closed form and, on Gaussian mixtures, the **exact score** against the learned score; samplers against exact solutions where they exist. **Relationship to neighbouring modules:** Module 04's convolutions and Module 06's contrastive objectives are **reused, not re-taught**; Module 07's attention, Module 09's GPT, Module 11's SFT, and Module 12's cache are **reused as components**; **reasoning over images or audio (Module 13's methods) is named only**; reading and reproducing the multimodal literature is Module 15; serving multimodal workloads is Stage 5D.

## Conventions stated once, used everywhere (state them in Unit 0, apply in all units)

- **The modality-interface convention (signature habit).** **Every modality states its interface before any model is compared.** *Images:* `H × W × C`, patch size `P`, **patches per image `N = (H/P)·(W/P)` (an error if `P` does not divide `H` and `W`, or a stated padding rule)**, token dimension `D`, sequence length `N + n_special`. *Audio:* sampling rate `f_s` (Hz), samples `T`, frame length `L` and hop `H_op` (samples), **frames per clip `F = 1 + ⌊(T − L)/H_op⌋` without padding (or the stated centred-padding formula)**, mel bands `M`, the encoder's downsampling factor `s`, **tokens per second `= f_s/(H_op·s)`**. *Generation:* data dimension, number of diffusion steps `T_d`, **network evaluations (NFE) per sample**, whether guidance doubles them. **Layouts are fixed: images `(B, C, H, W)`; patch tokens `(B, N, D)`; spectrograms `(B, M, F)`; text `(B, T_text)`; every function documents its shapes, and a shape mix-up is a test failure.**
- **The compute-and-cost convention (inherited from Module 13 and extended).** Cost is stated in **tokens, FLOPs by the Module 10/12 formulas (`2N` per processed token plus the attention term `∝ (sequence length)²·D`), and bytes of KV cache**, with **image/audio tokens counted exactly like text tokens in the sequence they join**; **`[HYPOTHETICAL]` symbolic prices and latencies only; the only measured time is the learner's own CPU, at the edge, `[ILLUSTRATIVE]`**. **Methods are compared at equal compute (or equal parameters and equal training examples) via a mandatory parity table; accuracy-per-cost is reported with intervals.**
- **Planted-world and oracle conventions.** A **world** has a generator with a root seed, **exact ground-truth attributes per sample**, an **exact oracle for every task** (class, caption correctness, QA answer, transcript, true density/score), **templates (the unit of independence for resampling: scenes sharing a template or caption pattern are one cluster)**, **held-out compositions, held-out classes, and held-out templates** separated from training, and **controllable spurious correlations** (e.g., a background colour correlated with the label with strength `ρ`, which is `0` in the clean evaluation set and flipped in the adversarial evaluation set). **The world's generator, captions, and oracles are the module's own; nothing is scraped or downloaded.**
- **Baselines-and-ablations convention (mandatory companions of every headline number).** **Blind baselines** (the question only; the caption only; the image only; a shuffled-pair model whose pairs are random; a majority-class predictor; the planted chance rate), **shortcut baselines** (a predictor that uses only the spurious feature), **modality ablations** (zero or randomise one modality at test time), **counterfactual tests** (change exactly one attribute in the scene and check that the output changes as the oracle dictates; the *counterfactual consistency rate* is reported), and **the supervised baseline at an equal label budget** (a linear probe or a fully supervised model on the same data). **A headline result without its blind and shortcut baselines is a defect.**
- **Evaluation convention (inherited from Modules 11–13).** Programmatic checkers only; **no LLM judge; no eyeballed "quality"**; **template-cluster bootstraps (`B` stated) for intervals**; **paired comparisons on the same items use the exact McNemar test or a paired cluster bootstrap**; **results are stratified by category (colour, shape, count, position, relation; speaker/noise level; guidance scale) and by seen versus held-out composition**; **held-out data are never used for tuning; prompt templates, thresholds, temperatures, guidance scales, and step counts are tuned on tuning items and reported on held-out items, with the sweep's best-of-`k` optimism measured**; **sampling/noise seed, data seed, and training seed are separate variance sources; headline comparisons use ≥ 5 evaluation seeds and ≥ 3 training seeds (`--quick` 3/2)**.
- **Exact-oracle convention.** **Every transform and loss has an independent oracle that never imports the function under test**: patchify ↔ strided convolution and explicit loops; symmetric contrastive loss ↔ explicit double loop and `Fraction`/`float64` arithmetic; STFT ↔ direct `O(F·L²)` DFT; mel filterbank ↔ explicit triangular filters; CTC loss ↔ enumeration of all alignments of tiny `(T, V)`; WER ↔ DP edit distance and an exhaustive alignment search for tiny strings; diffusion forward process ↔ the closed form `x_t = √ᾱ_t x₀ + √(1 − ᾱ_t) ε` versus step-by-step noising; **on Gaussian mixtures the exact marginals and exact scores ↔ the learned network**; Fréchet distance ↔ `scipy.linalg.sqrtm` and closed forms for 1-D and diagonal cases. **`float64` in oracle tests; tolerances stated and justified.**
- **Random-stream convention.** Per-stream `torch.Generator`s and NumPy `SeedSequence` with named spawn keys (`world`, `augment`, `batch`, `noise`, `prompt`, `sample`, `bootstrap`); **never the global generator; data, noise, and training seeds distinct; tuning and reporting seeds disjoint.**
- **Fair-comparison protocol (inherited from Module 05, with Modules 11–13 additions).** Equal parameters and equal training examples (or equal FLOPs, stated) between compared architectures; **identical data, augmentation, optimiser, schedule, and tuning budget** (the unequal-tuning-budget trap is named); **≥ 5 evaluation seeds and ≥ 3 training seeds for headline comparisons (`--quick` 3/2)**; effect sizes with template-cluster intervals; trials reported; **no architecture or method ranking is ever stated** (link `../05-Sequence-Models-and-Tabular-Deep-Learning/README.md`, content not yet authored — mark `OPEN` until reconciled).
