## Unit 5 — Momentum, RMSprop, and Adam: intuition

- **L1:** **the problems these methods address** (S4B-07's zigzag on elongated bowls; different parameters needing different step sizes; noisy gradients); **momentum**: **keep a running "velocity" that averages recent gradients, so consistent directions accelerate and zigzag components cancel** — **the update in the pinned canonical form `v ← βv + g; θ ← θ − ηv`**, **the ball-rolling-downhill picture**, **`β = 0` recovers plain gradient descent (the first metamorphic test)**, **a hand run of three steps with exact `Fraction` arithmetic on a 1-D and a 2-D quadratic**; **RMSprop**: **divide each coordinate's step by a running root-mean-square of its recent gradients, so large-gradient coordinates take smaller steps and small-gradient coordinates larger ones** (`s ← ρs + (1 − ρ)g²; θ ← θ − η g/(√s + ε)`; **per-coordinate scaling is a diagonal "preconditioner"**; **a hand run with a perfect-square gradient sequence so the square roots are exact**); **Adam**: **momentum on the gradient (`m`) combined with RMSprop-style scaling (`v`), with a bias correction for the zero initialisation** (the pinned canonical form; **the role of `ε` (avoid division by zero) and of `t` starting at 1**; **a hand run of the first two steps with exact arithmetic**); **the typical hyperparameters (`β₁ = 0.9`, `β₂ = 0.999`, `ε = 10⁻⁸`, and a small `η`) are *commonly quoted conventions* `[VERIFY]` (Kingma & Ba), not rules and not guaranteed to suit any problem**; **a first comparison** on an elongated bowl: GD vs momentum vs RMSprop vs Adam on the same start and equal `η`-tuning budget — **path pictures and loss curves (`gdviz`/`optcompare` previews), read as findings about this problem**; ≥ 3 worked examples.
