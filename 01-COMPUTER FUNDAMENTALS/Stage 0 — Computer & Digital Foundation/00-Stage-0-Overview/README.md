# 00 — Stage 0 Overview

This folder contains the planning material for **Stage 0 — Computer, Linux, and Developer
Foundations**, separate from the teaching content itself (which lives in modules
`01-How-Computers-Work/` through `04-Developer-Environment/`).

**Roadmap source:** Stage 0 — Computer, Linux, and Developer Foundations (the audit-and-gap-closure
revision of the original Stage 0 — Computer & Digital Foundations scope).

## Contents

- [`learning-plan.md`](./learning-plan.md) — the single authoritative planning document for
  Stage 0. It covers the stage outcome, an audit of the original four modules (0.1–0.4), the six
  practical gaps (0A–0F) that close before Stage 1, recommended tools, Projects 0.1–0.5,
  engineering-thinking practices, parallel interview preparation, and the Stage 0 completion gate.

## How to use this folder

1. Read the **stage outcome** and **audit** sections of `learning-plan.md` first, to confirm what
   the four numbered modules (0.1–0.4) already cover and what evidence proves each is operational —
   not just read.
2. Work through **Gaps 0A–0F** in `learning-plan.md`. These are small, practical additions — Git
   and GitHub, safe terminal habits, local networking, a reproducible Python workspace, secrets
   hygiene, and engineering-thinking practice — that the original four modules did not cover.
3. Build **Projects 0.1–0.5** in order, using the recommended-tools table in `learning-plan.md` as
   a reference. Each project produces a real, version-controlled artifact.
4. Before moving to Stage 1, work through every checkbox in the **Stage 0 completion gate** at the
   end of `learning-plan.md` and confirm it can genuinely be demonstrated — not just recognized
   from reading — including the parallel interview-preparation questions.

Nothing in this folder is marked complete yet. Stage 0 is not finished until the completion gate in
`learning-plan.md` is met.

## Projects

See [`Projects/README.md`](./Projects/README.md) for the Stage 0 capstone project: a single,
complete incident simulation that draws on Modules 01–04 together — evidence-based debugging, safe
remediation, verification, and documentation — proving you can investigate and resolve a real
problem the way the rest of Stage 0's projects only practiced one piece of at a time.
