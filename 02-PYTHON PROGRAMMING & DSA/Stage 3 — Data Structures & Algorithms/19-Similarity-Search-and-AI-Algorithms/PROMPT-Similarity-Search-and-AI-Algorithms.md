**Conventions are stated once and used everywhere:**
- **Vectors and metrics:** a vector is a `tuple`/`list`/`array('d')` of finite `float`s or `int`s of a fixed dimension `d`; **`NaN`, `inf`, empty vectors, and dimension mismatches are rejected with `ValueError`**. **Metrics are explicit parameters, never implicit**: `l2sq` (squared Euclidean — **used for comparisons; `sqrt` only for display or when the triangle inequality is needed**), `l2`, `l1`, `cosine_distance = 1 − cos θ`, `neg_dot` (negative inner product, so "smaller is closer" uniformly). **A zero vector under cosine is rejected (or defined by a documented policy and tested).** **Cosine similarity of `a`, `b` equals the dot product of their unit-normalized versions; for unit vectors `‖a − b‖² = 2 − 2·a·b` (proved in Unit 1).** `neg_dot` and cosine are **not metrics** (triangle inequality fails — stated, with counterexample); pruning structures that need the triangle inequality are used only with metrics.
- **Numeric policy:** **exact tests use integer-valued vectors, so `l2sq`, `l1`, and `dot` are computed exactly in Python `int`s; floating-point tests state their tolerance and why.** Distances are accumulated in a **fixed left-to-right order** (documented) so results are reproducible; `math.fsum` is used only where stated. **Results are totally ordered by `(distance, id)`**, so ties are broken by smaller id — **deterministic ground truth**.
- **Ground truth and recall:** **exact kNN ground truth is computed by brute force with the same metric and the same tie-break.** **`recall@k` = `|returned ∩ exact top-k| / k`, with a documented tie policy: a returned item counts as correct if its distance is `≤` the exact `k`-th distance (so tie-sets are not penalized) — both strict-id and tie-tolerant recall are implemented and the difference shown.** **Evaluation queries are never drawn from the indexed points (no leakage), unless a lab explicitly demonstrates the leakage fallacy.** Recall is reported with the **number of queries, seeds, and a derived confidence statement (Hoeffding/Chebyshev tagged `CITED [VERIFY]` where not proved)**.
