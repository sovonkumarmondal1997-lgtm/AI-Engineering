## Unit 2 — Tree traversals
- **L1:** traversal = visiting every node exactly once in a defined order; **depth-first** orders on a binary tree: **preorder** (node, left, right), **inorder** (left, node, right), **postorder** (left, right, node) — a memory aid and hand traces on a 7-node tree; **breadth-first / level-order** with a queue (`deque`, S3-04 link); the output of each on the same tree side by side; recursive implementations of all three DFS orders (3–5 lines each); first use of traversal to print a tree, compute a sum, and copy a tree.
- **L2:** **iterative DFS** with an explicit stack for preorder, inorder, and postorder (the one-stack-with-state patterns: push-left-spine for inorder; reverse-of-modified-preorder and the **last-visited-pointer** method for postorder; a **"visited flag" tuple** pattern that unifies all three — implement and compare for clarity); **level-order variants**: by levels (list of lists), right-to-left, **zigzag**, bottom-up, level averages, maximum per level; **n-ary tree traversals**; **generators** with `yield` and `yield from` for lazy traversals (and the generator-recursion cost: each element passes up through O(depth) generators — measured); **iterator objects** (an inorder iterator with an explicit stack using O(h) memory — the "BST iterator" pattern with `__iter__`/`__next__`); traversal with a callback/visitor vs returning lists; **reconstructing a tree from two traversals** (preorder+inorder, postorder+inorder with a hash map of inorder positions for O(n); **why preorder+postorder is ambiguous** without fullness — counterexample); path-tracking during traversal (all root-to-leaf paths with backtracking, S3-05 Unit 2 link); grid/graph BFS/DFS as the generalization (module 08 forward link).
- **L3:** **correctness by structural induction** for each order (the output for a tree = a composition of the outputs for its subtrees and the root — state the formula and prove); the **iterative-inorder invariant** (the stack holds exactly the nodes whose left subtrees are being or have been processed and that are still to be visited, in ancestor order) with a full proof; **complexity**: O(n) time for every traversal (each node pushed/popped or enqueued/dequeued once; prove), **space O(h) for DFS** (stack depth equals the longest root-to-current path) and **O(w) for BFS** (w = maximum width — up to ⌈n/2⌉ for a perfect tree; prove the bound), and the contrast on skewed vs perfect trees (DFS O(n) vs O(log n); BFS O(1)–O(n/2)); **uniqueness theorems**: inorder + preorder (or postorder) determines a binary tree with **distinct** values — proof by induction on size; why duplicate values break it (counterexample); **the relationship** inorder of a BST is sorted (stated here, proved in Unit 3); traversal order and **tree-shape reconstruction counts** (how many trees share a preorder — Catalan link); **Morris traversal and Euler tours** named with forward links to Units 13–14; depth-first vs breadth-first decision table (memory, finding shortest/nearest, recursion safety, ordering needs).
